How it works

  1. 1
    Install once. Run the installer, enter your portal credentials once, done.
  2. 2
    Runs quietly in the background. Lives in your system tray.
  3. 3
    Detects when you're logged out. Checks the portal every 5 seconds. If you're out, it notices immediately.
  4. 4
    Logs you back in automatically. You just stay connected. No popup, no interruption.

How your password is handled

It never leaves your PC. Here's the exact path:

🔑 Your password
→
🔒 Windows DPAPI
→
💾 Encrypted file
on your PC only
→
⚙️ NexLink reads it
→
🌐 LMU portal
(HTTPS only)

DPAPI ties the encrypted file to your Windows user account. Even if someone copied the file off your machine, they couldn't read it without logging into your account.

Known limitations

  • Only works with LMU's specific Wi-Fi portal
  • Windows only (10 and 11)
  • Requires an internet-accessible portal to log into — won't help with general connectivity outages
  • You'll need to enter your credentials once, on first run
