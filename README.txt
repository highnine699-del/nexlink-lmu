NexLink v1.2.0

This installer installs the NexLink Wi-Fi monitor application (LMU campus edition).

What is included:
- NexLink.exe (WPF-based modern UI)
- wifi_icon.ico
- README.txt

Important:
- This installer does not include lmu_portal.cred.
- You must provide your portal credentials separately after installation.
- Run the application as Administrator for Wi-Fi control and portal login.

Features:
- Modern borderless window with status orb indicator
- Automatic connection to trusted campus networks
- Portal login automation
- Advanced panel for logs and credential management
- System tray integration with minimize-to-tray support

Usage:
1. Open the installed NexLink application.
2. Enter your portal username and password when prompted.
3. Leave it running to maintain connection and reconnect to trusted networks.
4. Click the ⚙ icon in the bottom-right to access advanced options (logs, re-enter credentials).

Status Indicators:
- Mint green orb: Connected and logged in
- Amber orb: Reconnecting or checking connection
- Red-pink orb: Error or offline

If you need support, keep this installer folder and the README for reference.
