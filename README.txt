NexLink v1.3.25

This installer installs the NexLink Wi-Fi monitor application (LMU campus edition).

What is included:
- NexLink.exe (WPF-based modern UI with Pro features)
- wifi_icon.ico
- README.txt

Important:
- This installer does not include lmu_portal.cred.
- You must provide your portal credentials separately after installation.
- Run the application as Administrator for Wi-Fi control and portal login.

Free Features:
- Modern borderless window with status orb indicator
- Automatic connection to trusted campus networks
- Portal login automation
- Advanced panel for logs and credential management
- System tray integration with minimize-to-tray support
- Auto-update notifications

Pro Features (requires license):
- Custom Themes: Choose from Cyberpunk, Sunset, and Midnight color schemes
- Future Pro features: Multi-network profiles, NetPulse integration, and more

To upgrade to Pro:
1. Click the "Enter Pro License" button in the Advanced panel (⚙ icon)
2. Complete payment via Paystack (secure payment processing)
3. Copy your license key from the success page
4. Paste the license key in NexLink and click Validate
5. Your license is stored securely on your machine and works offline

Usage:
1. Open the installed NexLink application.
2. Enter your portal username and password when prompted.
3. Leave it running to maintain connection and reconnect to trusted networks.
4. Click the ⚙ icon in the bottom-right to access advanced options:
   - Re-enter Credentials
   - Enter Pro License
   - Change Theme (Pro only)
   - Open Log File

Status Indicators:
- Mint green orb: Connected and logged in
- Amber orb: Reconnecting or checking connection
- Red-pink orb: Error or offline

If you need support, visit https://github.com/highnine699-del/nexlink-updates for documentation and to report issues.
